# Operating Systems

Thermal Berry is compatible with all devices running Windows or macOS. On Linux, compatibility is currently limited to Dell and Alienware devices.

The release workflow builds packages for the following platforms:

| Platform | Packages |
| --- | --- |
| Linux x86-64 | APT repository for Debian and Ubuntu, AppImage, DEB, and RPM |
| Windows | NSIS installer (`.exe`) |
| macOS | Universal disk image (`.dmg`) for Intel and Apple Silicon |
